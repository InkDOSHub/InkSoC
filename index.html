Installed programs
Windows

A full controller over the program's screen: two sticks, D-pad, A B X Y, L1 R1 L2 R2, Select and Start. Games that support controllers see an Xbox controller; games that only read the keyboard get arrows, Z X A S, Q W E R, Enter and Esc. "Edit" moves controls and changes their size. A controller connected to this device (Bluetooth or USB) works too, even with these hidden.

InkSoC runs Windows programs (.exe, 64-bit and 32-bit) in this tab with its own engine: no Wine install, no Linux, nothing sent to a server.

Drive C: lives in this browser's private storage and stays after a reload. To bring a program in, drop its file on the desktop or use "Copy here…" in File Explorer; it lands in Downloads, and a double tap opens it there (.exe runs, .msi installs, .zip unpacks). Installed programs appear in Start.

Each running program gets a button in the bar: tap it to bring it to the front or hide it. Windows move by their title bar and change size by their bottom-right corner; the maximize button fills the screen. Several cores need the hub.inkdos.workers.dev address.

InkSoC is shut down.
Every program stopped and drive C: is saved.
