# Icons

From the Papirus icon theme (https://github.com/PapirusDevelopmentTeam/papirus-icon-theme),
64x64 SVGs, unchanged. Papirus is free software under the GNU General Public License 3.0
(https://www.gnu.org/licenses/gpl-3.0.html); these files keep that license. The shell only
shows them as images.

`sym/`: one-colour (symbolic) icons from Papirus 16x16, same license. The page draws them in the text colour with a CSS mask.
